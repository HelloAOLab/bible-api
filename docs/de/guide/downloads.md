# Downloads

Zusätzlich zur Verfügbarkeit als HTTP-API bieten wir die Inhalte auch in herunterladbaren Formaten an:

-   [api.zip](https://bible.helloao.org/api.zip) (1,5 GB) – Die API ist als ZIP-Datei verfügbar. Einfach herunterladen und entpacken, um die gesamte Bibel-API auf Ihrem Computer zu nutzen.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) – Alle Inhalte der Bibel-API sind als [SQLite-](https://www.sqlite.org/index.html) Datenbank verfügbar. Diese Version erleichtert die Suche in über 1000 Übersetzungen zum Vergleich und zur Datenanalyse erheblich.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1,5 GB) – Alle englischen Bibelübersetzungen der API sind als [SQLite-](https://www.sqlite.org/index.html) Datenbank verfügbar. Diese Version erleichtert die Suche in über 1000 Übersetzungen zum Vergleich und zur Datenanalyse erheblich.
