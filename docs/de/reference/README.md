# API

Referenzdokumentation für die Free Use Bible API, nach Kategorien geordnet:

-   [**Übersetzungen, Bücher & Kapitel**](./translations/README.md) – Bibelübersetzungen, ihre Bücher und Kapitelinhalte sind in [Standard-](./translations/standard.md) und [vereinfachten](./translations/simplified.md) Formaten erhältlich.
-   [**Kommentare**](./commentaries/README.md) – Bibelkommentare, ihre Bücher, Kapitel und Profile.
-   [**Datensätze**](./datasets/README.md) – ergänzende Datensätze, wie z. B. Querverweise und biblische Entitäten (Personen, Orte, Ereignisse und Volksgruppen) sowie deren Bücher, Kapitel und Entitäten.
-   [**OpenAPI**](./openapi.md) – das OpenAPI-Dokument, das die API beschreibt und mit der Sie Clients für andere Sprachen generieren können.
