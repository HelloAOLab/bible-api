# Descargas

Además de estar disponible como una API HTTP, hemos puesto el contenido a disposición en formatos descargables:

-   [api.zip](https://bible.helloao.org/api.zip) (1,5 GB): La API está disponible en un archivo zip. Simplemente descárguelo y descomprímalo para tener la API completa de la Biblia disponible en su computadora.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB): Todo el contenido de la API de la Biblia está disponible como base de datos [SQLite](https://www.sqlite.org/index.html) . Esta versión facilita enormemente la búsqueda entre más de 1000 traducciones para su comparación y análisis de datos.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1,5 GB): Todas las traducciones al inglés de la Biblia disponibles en la API como base de datos [SQLite](https://www.sqlite.org/index.html) . Esta versión facilita la búsqueda entre más de 1000 traducciones para su comparación y análisis de datos.
