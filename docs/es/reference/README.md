# API

Documentación de referencia para la API de la Biblia de uso libre, organizada por categoría:

-   [**Traducciones, Libros y Capítulos**](./translations/README.md) - Traducciones de la Biblia, sus libros y el contenido de sus capítulos, disponibles en formatos [estándar](./translations/standard.md) y [simplificados](./translations/simplified.md) .
-   [**Comentarios**](./commentaries/README.md) bíblicos: comentarios sobre la Biblia, sus libros, capítulos y perfiles.
-   [**Conjuntos de datos**](./datasets/README.md) : conjuntos de datos complementarios, como referencias cruzadas, entidades bíblicas (personas, lugares, eventos y grupos de personas), palabras interlineales en el idioma original, un léxico de Strong y posibles versículos del día, así como sus libros, capítulos, entidades y categorías de versículos.
-   [**OpenAPI**](./openapi.md) : el documento OpenAPI que describe la API, que puede utilizar para generar clientes para otros lenguajes.
