# डाउनलोड

HTTP API के रूप में उपलब्ध होने के अलावा, हमने सामग्री को डाउनलोड करने योग्य प्रारूपों में भी उपलब्ध कराया है:

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - API एक ज़िप फ़ाइल में उपलब्ध है। बस डाउनलोड करें और अनज़िप करें, जिससे पूरी बाइबिल API आपके स्थानीय कंप्यूटर पर उपलब्ध हो जाएगी।
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - बाइबिल API की सभी सामग्री [SQLite](https://www.sqlite.org/index.html) डेटाबेस के रूप में उपलब्ध है। यह संस्करण 1000 से अधिक अनुवादों में तुलना और डेटा विश्लेषण के लिए खोज करना बहुत आसान बनाता है।
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - [SQLite](https://www.sqlite.org/index.html) डेटाबेस के रूप में उपलब्ध बाइबिल API के सभी अंग्रेजी अनुवाद। यह संस्करण 1000 से अधिक अनुवादों में तुलना और डेटा विश्लेषण के लिए खोज करना बहुत आसान बनाता है।
