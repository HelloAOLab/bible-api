# एपीआई

फ्री यूज़ बाइबल एपीआई के लिए संदर्भ दस्तावेज़, श्रेणी के अनुसार व्यवस्थित:

-   [**अनुवाद, पुस्तकें और अध्याय**](./translations/README.md) - बाइबिल के अनुवाद, उनकी पुस्तकें और अध्यायों की सामग्री, [मानक](./translations/standard.md) और [सरलीकृत](./translations/simplified.md) प्रारूपों में उपलब्ध हैं।
-   [**टीकाएँ**](./commentaries/README.md) - बाइबिल की टीकाएँ, उनकी पुस्तकें, अध्याय और विवरण।
-   [**डेटासेट**](./datasets/README.md) - पूरक डेटासेट, जैसे कि क्रॉस संदर्भ और बाइबिल संबंधी संस्थाएं (लोग, स्थान, घटनाएं और जनसमूह), और उनकी पुस्तकें, अध्याय और संस्थाएं।
-   [**OpenAPI**](./openapi.md) - यह OpenAPI दस्तावेज़ API का वर्णन करता है, जिसका उपयोग आप अन्य भाषाओं के लिए क्लाइंट बनाने के लिए कर सकते हैं।
