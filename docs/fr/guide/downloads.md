# Téléchargements

En plus d'être disponible sous forme d'API HTTP, nous avons rendu le contenu disponible dans des formats téléchargeables :

-   [api.zip](https://bible.helloao.org/api.zip) (1,5 Go) - L'API est disponible dans un fichier zip. Il suffit de le télécharger et de le décompresser pour accéder à l'intégralité de l'API biblique sur votre ordinateur.
-   [bible.db](https://bible.helloao.org/bible.db) (11 Go) - L'intégralité du contenu de l'API biblique est disponible sous forme de base de données [SQLite](https://www.sqlite.org/index.html) . Cette version facilite grandement la recherche parmi plus de 1 000 traductions à des fins de comparaison et d'analyse des données.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1,5 Go) - Toutes les traductions anglaises de l'API biblique sont disponibles sous forme de base de données [SQLite](https://www.sqlite.org/index.html) . Cette version facilite grandement la recherche parmi plus de 1 000 traductions à des fins de comparaison et d'analyse des données.
