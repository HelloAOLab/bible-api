# API

フリーユース聖書APIのリファレンスドキュメント（カテゴリ別）：

-   [**翻訳、書物、章**](./translations/README.md)- 聖書の翻訳、各書物、章の内容を、[標準](./translations/standard.md)形式と[簡略](./translations/simplified.md)形式で提供しています。
-   [**解説書**](./commentaries/README.md)- 聖書解説書、その書、章、および概要。
-   [**データセット**](./datasets/README.md)- 相互参照や聖書の実体（人物、場所、出来事、民族集団）、およびそれらに対応する書物、章、実体などの補足データセット。
-   [**OpenAPI**](./openapi.md) - 他の言語用のクライアントを生成するために使用できるAPIを説明するOpenAPIドキュメント。
