# ダウンロード

HTTP APIとして利用できるだけでなく、ダウンロード可能な形式でもコンテンツを提供しています。

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - APIはzipファイルで提供されています。ダウンロードして解凍するだけで、Bible API全体をローカルコンピュータで利用できるようになります。
-   [bible.db](https://bible.helloao.org/bible.db) （11GB） - Bible APIに含まれるすべてのコンテンツを[SQLite](https://www.sqlite.org/index.html)データベースとして提供します。このバージョンでは、1000を超える翻訳版を簡単に検索し、比較やデータ分析を行うことができます。
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - Bible API のすべての英語翻訳を[SQLite](https://www.sqlite.org/index.html)データベースとして提供します。このバージョンを使用すると、1000 を超える翻訳を比較したりデータ分析したりする際に、検索がはるかに容易になります。
