# 導入

聖書は、まさに神の霊感を受けた言葉であり、世界の歴史において最も重要な文書群です。世界中の様々な文化圏で幾世代にもわたり研究され、私たちの存在の根幹を成す多くの真理がそこに記されています。

## 私たちについて

[AO Labは、](https://helloao.org/)神の言葉を愛し、実践することに専念する非営利団体です。このプロジェクトの目標は、聖書（および関連資料）を必要とするすべての人に、アプリケーションでの利用に最適化された形式で無料で提供することです。

[BSBチーム](https://bereanbibles.com/)と提携できることを大変嬉しく思います。彼らの協力と支援がなければ、このAPIは実現しなかったでしょう。

BSBについてもっと詳しく知りたい場合は、[こちらをクリックして](https://bereanbibles.com/about-berean-study-bible/)ください。

## 翻訳に関する注記

聖書はもともと古代ヘブライ語、ギリシャ語、アラム語で書かれましたが、現在では主に英語、ドイツ語、スペイン語といった現代語への翻訳版として読まれています。古代ヘブライ語とギリシャ語は現代語とは大きく異なるため、翻訳者は聖書を英語などの現代語に正確かつ的確に訳すために、多くの判断を下さなければなりません。結果として、翻訳は究極的には、多くの熟慮と歴史的背景を必要とする創造的な解釈のプロセスとなります。したがって、聖書を現代語に翻訳した決定版は存在しません。これは決して聖書の信頼性を否定するものではありませんが、単一の翻訳版だけを読むと、原著者の意図を誤解するリスクがあることを示唆しています。

今日では、聖書の様々な翻訳が行われており、それぞれが異なるアプローチを取り、異なる考え方を重視しながら、聖書を正確かつ分かりやすく伝えようと試みている。どの翻訳者も、それぞれの言語で聖書を理解できるようにすることを目指しているが、その目的を達成するためのアプローチは様々である。

::: tip
例えば、翻訳者は歴史的に、ヘブライ語やギリシャ語の単語の本来の意味を特定し、それに相当する英語やスペイン語などに翻訳する「逐語訳」のアプローチを取るか、フレーズや概念の本来の意味を見つけ出し、それに相当する意味に翻訳する「意訳」のアプローチを取るかを選択しなければなりませんでした。

現代の翻訳の多くは、原文の正確さを保ちつつ、翻訳先の言語で自然に感じられる表現にたどり着くために、複数の手法を組み合わせている。
:::

翻訳の大部分は内容において一致していることは重要ですが、特定の翻訳を深く読み解くと誤解を招く可能性があります。なぜなら、原文には翻訳では表現しにくい含意やニュアンスが存在する場合があり、また、注意深く検討しなければ、翻訳言語には原著者の意図とは異なる示唆的な考えが含まれている可能性があるからです。

聖書を読む際には、自分が何を理解しようとしているのかを自問し、その目的を達成できる翻訳を一つ以上選択することが重要です。例えば、単に楽しみや基本的な理解のために聖書を読むのであれば、 [BSB](https://bereanbibles.com/) 、 [ESV](https://www.esv.org/) 、 [NASB](https://www.lockman.org/new-american-standard-bible-nasb/)などの現代語訳を選べばよいでしょう。しかし、特定の言い回しやニュアンスを理解しようとしているのであれば、複数の翻訳を比較したり、原文のヘブライ語やギリシャ語を簡単に確認できる逐語訳聖書を入手したりするのが良いでしょう。

しかし、何よりも大切なのは、聖霊の導きによる知恵を求める祈りです。イエスの言葉にあるように、 **「真理の御霊が、あなたがたをすべての真理へと導いてくださるでしょう。」（ヨハネによる福音書16章13節）**
