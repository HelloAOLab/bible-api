# 聖書のライセンス付与に関する聖書的モデル

**「あなたがたはただで受けたのだから、ただで与えなさい。」 - マタイによる福音書 10:8**

キリスト教徒は、イエスの言葉はまさに神の言葉であり、イエス自身があらゆる安楽を捨てて人間の姿をとり、私たちの苦しみを分かち合うという大きな犠牲を払って、人類に無償で与えられたものだと信じている。

同様に、私たちは決して、他者が神の言葉を称えるような体験を創造することを妨げるような、有料購読制やその他の障壁を設けるつもりはありません。

聖書の完全かつ高品質な英語訳を、APIを通じて無料で、かつ利用制限なく世界に提供してくれるパートナーを探しましたが、残念ながら、そのような協力をしてくれるパートナーはごく少数しか見つかりませんでした。特に、このAPIを実現してくれた[ベレア聖書チーム](https://berean.bible/)には、言葉では言い表せないほど深く感謝しています。

ベレア聖書の作成は、必然的な必要性から生まれました。BibleHub[の](https://biblehub.com/)運営チームは、一般向けにサービスを提供してきた中で、ライセンス提供者がアップデート時にライセンスを取り消したり、使用期限が切れたり、その他多くの関連問題に直面してきた長年の経験から、この翻訳を考案しました。そしてついに、BibleHubチームは、出版社やライセンス提供者の制限を受けることなく、世界中の人々が自由に英語訳を利用できるように、独自の翻訳を作成することを決意したのです。

もしあなたが、同様に無料で利用制限なしにテキストを公開する意思のある他の聖書翻訳をお持ち、またはご存知でしたら、 [hello@helloao.org](mailto:hello@helloao.org)までご連絡ください。

最後に、聖書の著作権者や出版社がライセンスによってその利用を制限している場合、イエスが再臨された際に彼らに何と言われるかを真剣かつ慎重に検討されるよう祈ります。

ありがとう！

-AOラボチーム
