# واجهة برمجة التطبيقات (API)

الوثائق المرجعية لواجهة برمجة تطبيقات الكتاب المقدس للاستخدام المجاني، مصنفة حسب الفئة:

-   [**الترجمات والكتب والفصول**](./translations/README.md) - ترجمات الكتاب المقدس وكتبها ومحتوى فصولها، متوفرة بتنسيقات [قياسية](./translations/standard.md) [ومبسطة](./translations/simplified.md) .
-   [**التعليقات**](./commentaries/README.md) - تعليقات الكتاب المقدس، وكتبها، وفصولها، وملفاتها التعريفية.
-   [**مجموعات البيانات**](./datasets/README.md) - مجموعات البيانات التكميلية، مثل المراجع المتقاطعة والكيانات الكتابية (الأشخاص والأماكن والأحداث والجماعات البشرية)، وكتبها وفصولها وكياناتها.
-   [**OpenAPI**](./openapi.md) - وثيقة OpenAPI التي تصف واجهة برمجة التطبيقات (API)، والتي يمكنك استخدامها لإنشاء عملاء للغات أخرى.
