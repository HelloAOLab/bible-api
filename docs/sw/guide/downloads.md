# Vipakuliwa

Mbali na kupatikana kama API ya HTTP, tumefanya maudhui yapatikane katika miundo inayoweza kupakuliwa:

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - API inapatikana katika faili ya zip. Pakua na ufungue zip ili API nzima ya Biblia ipatikane kwenye kompyuta yako ya karibu.
-   [bible.db](https://bible.helloao.org/bible.db) (GB 11) - Maudhui yote katika API ya Biblia yanapatikana kama hifadhidata ya [SQLite](https://www.sqlite.org/index.html) . Toleo hili hurahisisha zaidi kutafuta tafsiri zaidi ya 1000 kwa ajili ya kulinganisha na uchambuzi wa data.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - Tafsiri zote za Kiingereza za API ya Biblia zinapatikana kama hifadhidata [ya SQLite](https://www.sqlite.org/index.html) . Toleo hili hurahisisha zaidi kutafuta tafsiri zaidi ya 1000 kwa ajili ya kulinganisha na uchambuzi wa data.
