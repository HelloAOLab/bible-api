# Unduhan

Selain tersedia sebagai API HTTP, kami juga menyediakan konten dalam format yang dapat diunduh:

-   [api.zip](https://bible.helloao.org/api.zip) (1,5 GB) - API tersedia dalam file zip. Cukup unduh dan ekstrak untuk mendapatkan seluruh API Alkitab di komputer lokal Anda.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - Semua konten dalam API Alkitab tersedia sebagai basis data [SQLite](https://www.sqlite.org/index.html) . Versi ini memudahkan pencarian melalui lebih dari 1000 terjemahan untuk perbandingan dan analisis data.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1,5 GB) - Semua terjemahan Alkitab dalam bahasa Inggris tersedia sebagai basis data [SQLite](https://www.sqlite.org/index.html) . Versi ini memudahkan pencarian lebih dari 1000 terjemahan untuk perbandingan dan analisis data.
