# API

Dokumentasi referensi untuk API Alkitab Penggunaan Gratis, diorganisir berdasarkan kategori:

-   [**Terjemahan, Kitab, & Bab**](./translations/README.md) - Terjemahan Alkitab, kitab-kitabnya, dan isi babnya, tersedia dalam format [standar](./translations/standard.md) dan [sederhana](./translations/simplified.md) .
-   [**Tafsir**](./commentaries/README.md) - Tafsir Alkitab, buku-buku, bab-bab, dan profilnya.
-   [**Kumpulan data**](./datasets/README.md) - kumpulan data tambahan, seperti referensi silang dan entitas alkitabiah (orang, tempat, peristiwa, dan kelompok orang), serta kitab, bab, dan entitasnya.
-   [**OpenAPI**](./openapi.md) - dokumen OpenAPI yang menjelaskan API, yang dapat Anda gunakan untuk menghasilkan klien untuk bahasa lain.
