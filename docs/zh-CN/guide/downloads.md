# 下载

除了提供 HTTP API 版本外，我们还提供了可下载格式的内容：

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - 此 API 以 zip 文件形式提供。只需下载并解压缩，即可在本地计算机上使用完整的圣经 API。
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - 圣经 API 中的所有内容均以[SQLite](https://www.sqlite.org/index.html)数据库的形式提供。此版本使搜索 1000 多个译本进行比较和数据分析变得更加容易。
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - 所有圣经 API 的英文译本均以[SQLite](https://www.sqlite.org/index.html)数据库的形式提供。此版本使搜索 1000 多个译本进行比较和数据分析变得更加容易。
