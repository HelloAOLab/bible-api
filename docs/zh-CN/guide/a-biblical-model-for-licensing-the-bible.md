# 圣经授权的圣经模式

**“你们白白地得来，也要白白地舍去。”——马太福音 10:8**

基督徒相信耶稣的话语正是上帝的话语，是上帝为了人类而无偿赐予的，耶稣自己为此付出了巨大的代价，他放弃了一切舒适的生活，取了人的样式，与我们一同承受苦难。

同样，我们绝不会设置任何付费墙或其他障碍，阻止他人创造荣耀上帝话语的体验。

为了找到一位愿意通过API免费向全世界分享完整、高质量英文圣经译本且不设使用限制的合作伙伴，我们遗憾地发现，愿意这样做的合作伙伴寥寥无几。尤其值得一提的是，我们对[Berean Bible团队](https://berean.bible/)感激不尽，正是他们的努力才使得这个API成为可能。

贝里亚圣经的诞生源于实际需要。BibleHub[的](https://biblehub.com/)领导层多年来一直致力于为公众提供服务，但他们也亲身经历了授权方在更新后撤销授权、期限到期以及其他诸多相关问题。最终，BibleHub 团队决定创建自己的译本，以确保全世界都能自由使用不受出版商或授权方限制的英文译本。

如果您有或知道其他任何圣经译本也愿意免费提供文本且不设使用限制，请通过[hello@helloao.org](mailto:hello@helloao.org)与我们联系。

最后，我们祈祷每一位通过许可限制圣经文本使用的版权持有者或出版商，都能认真仔细地思考耶稣再来时可能会对他们说什么。

谢谢你！

AO实验室团队
