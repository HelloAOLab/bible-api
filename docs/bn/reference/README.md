# এপিআই

ফ্রি ইউজ বাইবেল এপিআই-এর রেফারেন্স ডকুমেন্টেশন, বিভাগ অনুসারে সাজানো:

-   [**অনুবাদ, গ্রন্থ ও অধ্যায়**](./translations/README.md) - বাইবেলের অনুবাদসমূহ, সেগুলোর গ্রন্থ এবং অধ্যায়ের বিষয়বস্তু, যা [প্রমিত](./translations/standard.md) ও [সরলীকৃত](./translations/simplified.md) বিন্যাসে উপলব্ধ।
-   [**ভাষ্যগ্রন্থ**](./commentaries/README.md) - বাইবেলের ভাষ্যগ্রন্থ, সেগুলোর গ্রন্থ, অধ্যায় এবং পরিচিতি।
-   [**ডেটা সেট**](./datasets/README.md) - সম্পূরক ডেটা সেট, যেমন ক্রস রেফারেন্স এবং বাইবেলের সত্তাসমূহ (ব্যক্তি, স্থান, ঘটনা এবং জনগোষ্ঠী), এবং তাদের বই, অধ্যায় ও সত্তাসমূহ।
-   [**ওপেনএপিআই**](./openapi.md) - এটি হলো ওপেনএপিআই ডকুমেন্ট যা এপিআই-এর বর্ণনা দেয় এবং যা ব্যবহার করে আপনি অন্যান্য ভাষার জন্য ক্লায়েন্ট তৈরি করতে পারেন।
