# ডাউনলোড

HTTP API হিসেবে উপলব্ধ থাকার পাশাপাশি, আমরা কন্টেন্ট ডাউনলোডযোগ্য ফরম্যাটেও উপলব্ধ করেছি:

-   [api.zip](https://bible.helloao.org/api.zip) (১.৫ জিবি) - এপিআইটি একটি জিপ ফাইলে রয়েছে। সম্পূর্ণ বাইবেল এপিআই আপনার স্থানীয় কম্পিউটারে পেতে, শুধু ডাউনলোড করে আনজিপ করুন।
-   [bible.db](https://bible.helloao.org/bible.db) (১১ জিবি) - বাইবেল এপিআই-এর সমস্ত কন্টেন্ট একটি [SQLite](https://www.sqlite.org/index.html) ডেটাবেস হিসেবে উপলব্ধ। এই সংস্করণটি তুলনা এবং ডেটা বিশ্লেষণের জন্য ১০০০-এরও বেশি অনুবাদের মধ্যে অনুসন্ধান করা অনেক সহজ করে তোলে।
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (১.৫ জিবি) - বাইবেল এপিআই-এর সমস্ত ইংরেজি অনুবাদ একটি [SQLite](https://www.sqlite.org/index.html) ডেটাবেস হিসেবে উপলব্ধ। এই সংস্করণটি তুলনা এবং ডেটা বিশ্লেষণের জন্য ১০০০-এরও বেশি অনুবাদের মধ্যে অনুসন্ধান করা অনেক সহজ করে তোলে।
