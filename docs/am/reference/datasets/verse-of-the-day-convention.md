# የዕለቱ ኮንቬንሽን ጥቅስ

ይህ ገጽ የዕለቱን ጥቅስ ከ [`verse-of-the-day` የውሂብ ስብስብ](./README.md#verse-of-the-day) እንዴት እንደሚመርጡ ይገልጻል፣ በዚህም በማንኛውም ቋንቋ ተግባራዊ ማድረግ እና እንደሌሎች አተገባበሮች ተመሳሳይ ጥቅስ ማግኘት ይችላሉ።

ኤፒአይው ከስታቲስቲክ ፋይሎች የተሰራ ስለሆነ ለእርስዎ አንድም ጥቅስ አይመርጥም። ኮንቬንሽኑ የተጋራ ነባሪ ነው፡ እሱን የሚከተሉ መተግበሪያዎች በተመሳሳይ ቀን ተመሳሳይ ጥቅስ ያሳያሉ። መተግበሪያዎች በተለየ መንገድ መምረጥ ይችላሉ፣ እና [ዘሩ](#seeds) ተመሳሳይ ዋስትናዎችን እየጠበቁ ያንን ለማድረግ ቀላል መንገድ ይሰጣቸዋል።

## ዋስትናዎች

-   **ቆራጥ።** ተመሳሳዩ ቀን (እና ዘር) ሁልጊዜም ተመሳሳይ ጥቅስ፣ በእያንዳንዱ መሳሪያ እና በእያንዳንዱ አተገባበር ይሰጣል።
-   **በአንድ ዓመት ውስጥ ምንም ድግግሞሽ የለም።** እያንዳንዱ ዓመት የራሱ የሆነ የተወዛወዘ የጥቅሶቹ ቅደም ተከተል አለው፣ እና የዓመቱ ቀናት በእሱ ውስጥ ያልፋሉ። የውሂብ ስብስቡ ሁልጊዜ ጥቅም ላይ ለሚውሉ ለእያንዳንዱ ቀን ቢያንስ 366 ጥቅሶች አሉት፣ ስለዚህ አንድ ጥቅስ በተመሳሳይ የቀን መቁጠሪያ ዓመት ውስጥ ሁለት ጊዜ አይታይም።
-   **በዓላት።** በክርስቲያናዊ በዓል (እንደ ገና ወይም የትንሣኤ እሁድ)፣ የዕለቱ ጥቅስ ከበዓላቱ ጥቅሶች አንዱ ነው። አንድ በዓል በአንድ ዓመት በአንድ ጊዜ ጥቅሶቹን ስለሚያሳልፍ፣ ሁሉም ጥቅሶቹ እስኪተገበሩ ድረስ በየዓመቱ የተለየ ጥቅስ ይኖረዋል። ለብዙ ቀናት የሚቆይ በዓል (እንደ ከትንሣኤ እሁድ በኋላ ባሉት ሦስት ቀናት) በእያንዳንዱ ቀን የተለየ ጥቅስ አለው። የበዓላት ጥቅሶች በሌሎች ቀናት ጥቅም ላይ አይውሉም።
-   **በየአመቱ አዲስ ትዕዛዝ።** እያንዳንዱ ጥቅስ ከተጠቀሰ በኋላ ትዕዛዙ አይደገምም። እያንዳንዱ ዓመት ለየብቻ ስለሚቀላቀል፣ ተመሳሳይ ጥቅስ አልፎ አልፎ በታህሳስ 31 እና በጥር 1 (ከ650 አዲስ ዓመታት ውስጥ 1) ሊታይ ይችላል።
-   **የተረጋጋ ታሪክ።** የውሂብ ስብስቡ ገና ያልጀመረን ዓመት ጥቅሶችን ብቻ ይጨምራል ወይም ያስወግዳል ( [`addedIn` እና `removedIn`](#step-2-keep-the-verses-that-are-in-use) ይመልከቱ)፣ ስለዚህ አስቀድሞ የተከሰተ ቀን የቀኑ ጥቅስ ፈጽሞ አይለወጥም።
-   **ከዝርዝር ቅደም ተከተል ነፃ የሆነ።** የእያንዳንዱ ጥቅስ ቦታ በአንድ ዓመት ቅደም ተከተል ከራሱ ማጣቀሻ የመነጨ ስለሆነ የዝርዝሩ ቅደም ተከተል ምንም ለውጥ አያመጣም።

## አልጎሪዝም

### ደረጃ 1፡ የዓመቱን ዓመት እና ቀን ያግኙ

የቀን፣ የወር እና የዓመቱን ቀን እና የዓመቱን ቀን ከ0 ጀምሮ ውሰድ፤ ጥር 1 ቀን 0 ነው፣ ታህሳስ 31 ቀን 364 ነው (ወይም በመዝለል ዓመት ቀን 365)።

ቀኖች የፕሮሌፕቲክ ግሪጎሪያን የቀን መቁጠሪያን ይጠቀማሉ፡- አንድ ዓመት በ4 የሚከፈል ከሆነ የመዝለል ዓመት ነው፣ በ100 የሚከፋፈሉ እና በ400 የማይከፋፈሉ ዓመታት በስተቀር (2000 የመዝለል ዓመት ነው፣ 1900 ግን አይደለም)።

### ደረጃ 2፡ ጥቅም ላይ የዋሉትን ጥቅሶች ያስቀምጡ

በዓመቱ ውስጥ ጥቅም ላይ የሚውሉትን ጥቅሶች ያስቀምጡ፡

-   `addedIn` ጠፍቷል (ወይም ባዶ)፣ ወይም `addedIn <= year` ፣ እና
-   `removedIn` ጠፍቷል (ወይም ባዶ)፣ ወይም `year < removedIn` ።

### ደረጃ 3፡ ከጥቅሶቹ ውስጥ ለመምረጥ ምረጥ

ለመምረጥ የሚፈልጓቸውን ጥቅሶች፣ ለደረጃ 4 ቁልፍ ቅድመ ቅጥያ እና ለደረጃ 7 አቀማመጥ ይምረጡ፡

1. **ምድብ ተሰጥቷል።** `categories` የያዙትን ጥቅሶች በስራ ላይ ያቆዩ። ቅድመ ቅጥያው `{seed}|{year}` ሲሆን ቦታው ደግሞ የዓመቱ ቀን ነው።
2. **ምንም ምድብ አልተሰጠም፣ እና ቀኑ የበዓል ቀን ነው።** በ `holidays` ውስጥ ያለ የበዓል ቀን የዕለቱን `month` እና `day` ካለው ወይም ቀኑን በ `dates` ውስጥ (እንደ `YYYY-MM-DD` የተጻፈ፣ ባለአራት አሃዝ ዓመት) ከዘረዘረ ቀኑ የበዓል ቀን ነው። ከአንድ በላይ የበዓል ቀን የሚዛመድ ከሆነ፣ በዝርዝሩ ውስጥ የመጀመሪያውን ይጠቀሙ (የውሂብ ስብስቡ በተመሳሳይ ቀን ሁለት በዓላት የሉትም)። `categories` የበዓሉን `id` የያዙትን ጥቅሶች በስራ ላይ ያቆዩ። ካለ፣ ቅድመ ቅጥያው `{seed}|{id}` (ለምሳሌ `|christmas` ) እና ቦታው `year × k + i` ሲሆን፣ `k` በዓሉ በዓመት ውስጥ የሚከበርባቸው የቀናት ብዛት ነው ( `month` እና `day` ያለው ለበዓል፤ አለበለዚያ በቀኑ ዓመት ውስጥ ያለው `dates` ቁጥር) እና `i` ከቀኑ በፊት የሚመጡት የቀናት ብዛት ነው። በዓመት በአንድ ቀን ለሚከበር በዓል፣ ቦታው ዓመቱ ብቻ ነው። ከሌለ በ3 ይቀጥሉ።
3. **አለበለዚያ።** `categories` በ `holidays` ውስጥ የማንኛውም የበዓል ቀን `id` የማይይዙትን ጥቅሶች ይጠቀሙባቸው። ​​ቅድመ ቅጥያው `{seed}|{year}` ሲሆን ቦታው ደግሞ የዓመቱ ቀን ነው።

`seed` ዘር ነው (በነባሪነት ባዶ ሕብረቁምፊ)፣ እና `year` ከደረጃ 1 ጀምሮ ያለው ዓመት በአስርዮሽ ውስጥ መሪ ዜሮዎች በሌሉበት ነው (ለምሳሌ `2026` ፣ `1` )።

ምንም ጥቅሶች ካልተቀሩ የዕለቱ ጥቅስ የለም።

በየአመቱ የሚለዋወጡ በዓላት (በአሁኑ ጊዜ ከ2026 እስከ 2125) አስቀድመው የተሰላባቸውን ቀናት ብቻ ይዘረዝራሉ፣ ስለዚህ በሌሎች ዓመታት ተራ ቀናት ናቸው። ቀኖቹን እራስዎ አያስሉም።

### ደረጃ 5፡ እያንዳንዱን ቁልፍ ያዝ

የቁልፍ UTF-8 ባይቶችን ከ32-ቢት [FNV-1a](https://en.wikipedia.org/wiki/Fowler%E2%80%93Noll%E2%80%93Vo_hash_function) ሃሽ ጋር ያዋህዱ፣ ከዚያም ውጤቱን ከ [MurmurHash3](https://en.wikipedia.org/wiki/MurmurHash#Algorithm) `fmix32` የመጨረሻ አዛዥ ጋር ያዋህዱ። ሁሉም የሂሳብ አሃዞች ባልተፈረሙ 32-ቢት ኢንቲጀሮች ላይ ናቸው፣ ስለዚህ ማባዛቶች ይጠቀለላሉ (ሞዱሎ 2³² ይወሰዳሉ) እና የቀኝ ፈረቃዎች አመክንዮአዊ ናቸው (በዜሮዎች ይቀየራሉ)።

```
for each byte b in UTF-8(key):

hash = hash XOR (hash >> 16)

hash = hash XOR (hash >> 13)

hash = hash XOR (hash >> 16)
```

### ደረጃ 6፡ ጥቅሶቹን ደርድር

ጥቅሶቹን በመደርደሪያ ቁልፋቸው ለይ፣ በመጀመሪያ ትንሹን ለይ፣ ቁልፎቹን እንደ ያልተፈረሙ ቁጥሮች አወዳድር።

ሁለት ጥቅሶች ተመሳሳይ የመደርደር ቁልፍ ካላቸው (ይህም በጣም አልፎ አልፎ የሚከሰት)፣ ከደረጃ 4 ያለው የቁልፍ ሕብረቁምፊ በቅደም ተከተል (የቁምፊ ኮድ) ቅደም ተከተል መጀመሪያ የሚመጣውን መጀመሪያ ያስቀምጡ። የቁልፍ ሕብረቁምፊዎች ሁሉም የሚጀምሩት በተመሳሳይ ቅድመ ቅጥያ ነው፣ ስለዚህ በሚከተለው የASCII ማጣቀሻ ብቻ ይለያያሉ።

### ደረጃ 7፡ ጥቅሱን ምረጥ

የዕለቱ ጥቅስ በተደረደረው ዝርዝር ውስጥ `p mod n` ቦታ ላይ ያለው ጥቅስ ነው (ከ0 በመቁጠር)፣ `p` ደረጃ ከደረጃ 3 (የዓመቱ ቀን ወይም በበዓል ቀን `year × k + i` ) ያለው አቀማመጥ ሲሆን `n` ደግሞ በተደረደረው ዝርዝር ውስጥ ያሉት የቁጥሮች ብዛት ነው። የ `mod` ውጤት በጭራሽ አሉታዊ አይደለም (ለአሉታዊ ዓመት፣ `n` እስኪሆን ድረስ ይጨምሩ)።

በመደበኛ ቀናት፣ ሙሉው የውሂብ ስብስብ ቢያንስ 366 ቁጥሮች አሉት፣ ስለዚህ `day mod n` `day` ብቻ ነው። `mod` ቱ አስፈላጊ የሚሆነው በዓመቱ ውስጥ ካሉት ቀናት ያነሱ ጥቅሶች ካሉት ምድብ ወይም ዝርዝር ውስጥ ሲመርጡ ነው፣ በዚህ ጊዜ ጥቅሶች በዓመቱ ውስጥ ይደገማሉ። በበዓል ጊዜ፣ ቦታው የበዓሉን ጥቅሶች በአንድ ዓመት ውስጥ ያልፋል (እና ለብዙ ቀናት የሚቆይ በዓል ለአንድ ቀን)።

## የውሸት ኮድ

```
function verseOfTheDay(verses, holidays, date, seed = "", category = null):
    year = date.year
    day = dayOfYear(date)                 // 0 for January 1st
    inUse = [v for v in verses
             if (v.addedIn == null or v.addedIn <= year)
             and (v.removedIn == null or year < v.removedIn)]

    if category != null:
        return pick([v for v in inUse if category in v.categories], seed + "|" + year, day)

    holiday = first h in holidays where (h.month == date.month and h.day == date.day)
                                     or (h.dates contains format(date, "YYYY-MM-DD"))
    if holiday != null:
        holidayVerses = [v for v in inUse if holiday.id in v.categories]
        if holidayVerses is not empty:
            if holiday.dates == null:
                position = year
            else:
                datesInYear = [d for d in holiday.dates if d starts with year + "-"]
                position = year * length(datesInYear) + count of d in datesInYear where d < date
            return pick(holidayVerses, seed + "|" + holiday.id, position)

    holidayIds = [h.id for h in holidays]
    return pick([v for v in inUse if no category of v is in holidayIds], seed + "|" + year, day)

function pick(candidates, prefix, position):
    if candidates is empty: return null
    keyed = [(hash(key), key, v) for v in candidates
             where key = prefix + "|" + v.book + " " + v.chapter + ":" + v.verse]
    sort keyed by (hash, key)             // hash as an unsigned number, key in ordinal order
    return keyed[position mod length(keyed)].verse    // a mod that is never negative
```

## የተለመዱ ስህተቶች

-   **የተፈረሙ ኢንቲጀሮች።** ያልተፈረሙ 32-ቢት ኢንቲጀሮች (ጃቫ፣ ኮትሊን፣ ጃቫስክሪፕት) በሌሉባቸው ቋንቋዎች፣ በተፈረሙ 32-ቢት ኢንቲጀሮች ላይ ስሌት ያድርጉ እና አመክንዮአዊ የቀኝ ፈረቃ ( `>>>` ) ይጠቀሙ፣ ከዚያም ከማወዳደርዎ በፊት ውጤቱን ወደ ያልተፈረመ እሴት (ለምሳሌ `hash.toLong() and 0xFFFFFFFF` ፣ ወይም `hash >>> 0` በጃቫስክሪፕት) ይቀይሩት። በጃቫስክሪፕት ውስጥ፣ ለማባዛት `Math.imul` ይጠቀሙ፤ `*` ትክክለኛነትን ያጣል።
-   **በባይት ምትክ የፊደላት ሃሽ ማድረግ።** የቁልፉን የUTF-8 ባይት ሃሽ ያድርጉ፣ የUTF-16 ኮድ አሃዶችን ወይም የዩኒኮድ ኮድ ነጥቦችን አይደለም። ይህ ASCII-ያልሆኑ ቁምፊዎች ላሏቸው ዘሮች ብቻ አስፈላጊ ነው፣ ነገር ግን እነዚያ ይፈቀዳሉ።
-   **"ዛሬ" የሚለውን ቃል UTC በመጠቀም።** የቀኑ ጥቅስ በተጠቃሚው የአካባቢ እኩለ ሌሊት ላይ ይቀየራል። በUTC ውስጥ ያለውን ቀን መጠቀም በአብዛኛዎቹ የጊዜ ዞኖች ውስጥ የቀኑን ክፍል የቀደመውን ወይም የሚቀጥለውን ቀን ጥቅስ ያሳያል።
-   **የዓመቱን ቀን ከ1 ጀምሮ መቁጠር።** ጥር 1 ቀን 0 ነው።
-   **የበዓል ቀኖችን በማስላት ላይ።** በውሂብ ስብስቡ ውስጥ የተዘረዘሩትን `dates` ይጠቀሙ። የተለያዩ አብያተ ክርስቲያናት እና የቀን መቁጠሪያዎች ፋሲካን በተለየ መንገድ ያሰላሉ፣ እና የውሂብ ስብስቡ አስቀድሞ የተሰላባቸውን ቀናት ብቻ ይዘረዝራል።
-   **በዓላትን ችላ ማለት።** `holidays` ከሌለ፣ የበዓል ጥቅሶች እንደ ተራ ጥቅሶች ይቆጠራሉ፣ ይህም የእያንዳንዱን ተራ ቀን ጥቅስም ይለውጣል።
-   **የተወገዱ ጥቅሶችን ትተህ ውጣ።** `removedIn` ዓመት ያላቸው ጥቅሶች አሁንም በውሂብ ስብስቡ ውስጥ ናቸው ምክንያቱም ቀደምት ዓመታት ያስፈልጋቸዋል። በደረጃ 2 ያጣሯቸው፤ ዝርዝሩን ሲያወርዱ አይጣሉዋቸው።
