# ኤፒአይ

ለነፃ አጠቃቀም የመጽሐፍ ቅዱስ ኤፒአይ የማጣቀሻ ሰነድ፣ በምድብ የተደራጀ፡

-   [**ትርጉሞች፣ መጻሕፍት እና ምዕራፎች**](./translations/README.md) - የመጽሐፍ ቅዱስ ትርጉሞች፣ መጽሐፎቻቸው እና የምዕራፍ ይዘታቸው [በመደበኛ](./translations/standard.md) እና [በቀላል](./translations/simplified.md) ቅርጸቶች ይገኛሉ።
-   [**ሐተታዎች**](./commentaries/README.md) - የመጽሐፍ ቅዱስ ሐተታዎች፣ መጽሐፎቻቸው፣ ምዕራፎቻቸው እና መገለጫዎቻቸው።
-   [**የውሂብ ስብስቦች**](./datasets/README.md) - እንደ ተሻጋሪ ማጣቀሻዎች እና የመጽሐፍ ቅዱስ አካላት (ሰዎች፣ ቦታዎች፣ ክስተቶች እና የሰዎች ቡድኖች) እና መጽሐፎቻቸው፣ ምዕራፎቻቸው እና አካላቶቻቸው ያሉ ተጨማሪ የውሂብ ስብስቦች።
-   [**OpenAPI**](./openapi.md) - ለሌሎች ቋንቋዎች ደንበኞችን ለማመንጨት የሚጠቀሙበትን ኤፒአይ የሚገልጽ የ OpenAPI ሰነድ።
