# መግቢያ

መጽሐፍ ቅዱስ፣ በመንፈስ አነሳሽነት የተጻፈው የእግዚአብሔር ቃል፣ በዓለም ታሪክ ውስጥ እጅግ አስፈላጊ የሆኑ የሰነዶች ስብስብ ነው። ከመላው ዓለም በተውጣጡ ባህሎች ለብዙ ትውልዶች ጥናት ተደርጎበታል፣ እና መላው ሕይወታችን የተገነባባቸውን በርካታ መሠረታዊ እውነቶችን ይዟል።

## ስለ እኛ

[AO Lab](https://helloao.org/) የእግዚአብሔርን ቃል ለመውደድና ለማክበር የተቋቋመ ለትርፍ ያልተቋቋመ ኩባንያ ነው። የዚህ ፕሮጀክት ዓላማ መጽሐፍ ቅዱስን (እና ተዛማጅ ግብዓቶችን) ለሚፈልግ ማንኛውም ሰው በመተግበሪያዎች ጥቅም ላይ እንዲውል በተመቻቸ ቅርጸት በነፃ ማግኘት ነው።

[ከቢኤስቢ ቡድን](https://bereanbibles.com/) ጋር በመተባበር በጣም ጓጉተናል። የእነሱ እርዳታ እና ድጋፍ ባይኖር ኖሮ ይህ ኤፒአይ አይገኝም ነበር።

ስለ BSB የበለጠ ማወቅ ከፈለጉ እባክዎን [እዚህ ጠቅ ያድርጉ](https://bereanbibles.com/about-berean-study-bible/) ።

## ስለ ትርጉሞች ማስታወሻ

በመጀመሪያ የተጻፈው በጥንታዊ ዕብራይስጥ፣ ግሪክ እና አራማይክ ቋንቋ ሲሆን፣ አሁን በዋነኝነት እንደ እንግሊዝኛ፣ ጀርመንኛ እና ስፓኒሽ ባሉ ታዋቂ ዘመናዊ ቋንቋዎች የተተረጎሙ ትርጉሞች ስብስብ ሆኖ ያገለግላል። የጥንት ዕብራይስጥ እና ግሪክ ከዘመናዊ ቋንቋዎቻችን በጣም የተለዩ ስለሆኑ፣ አንድ ተርጓሚ መጽሐፍ ቅዱስን እንደ እንግሊዝኛ ባለ ዘመናዊ ቋንቋ በትክክል እና በትክክል ለመተርጎም ብዙ ውሳኔዎችን ማድረግ አለበት። በዚህም ምክንያት፣ ትርጉም በመጨረሻ ብዙ ምርምር እና ታሪካዊ አውድ የሚፈልግ የፈጠራ የትርጓሜ ሂደት ነው። ስለዚህ፣ መጽሐፍ ቅዱስን ወደ ዘመናዊ ቋንቋ አንድም ግልጽ የሆነ ትርጉም የለም። ይህ በአጠቃላይ የቅዱሳት መጻሕፍትን አስተማማኝነት በምንም መልኩ አያጎድልም፣ ነገር ግን አንድ ትርጉም ብቻ ካነበብን የመጀመሪያውን ጸሐፊ ዓላማ የመረዳት አደጋን እንድንጋፈጥ ያደርገናል።

ዛሬ መጽሐፍ ቅዱስን በትክክልና በትክክል ለመረዳትና ለመረዳት በሚያስችል መንገድ ተደራሽ ለማድረግ የተለያዩ የመጽሐፍ ቅዱስ ትርጉሞችን የተለያዩ አቀራረቦችንና የተለያዩ ሐሳቦችን ለማካተት የተለያዩ የመጽሐፍ ቅዱስ ትርጉሞች ተደርገዋል። እያንዳንዱ ተርጓሚ መጽሐፍ ቅዱስን በተወሰነ ቋንቋ ለመረዳት ይጥራል፣ ነገር ግን ለዚህ ዓላማ የተለያዩ አቀራረቦችን ሊጠቀም ይችላል።

::: tip
ለምሳሌ፣ ተርጓሚዎች በታሪክ ውስጥ የዕብራይስጥና የግሪክ ቃላትን የመጀመሪያ ትርጉሞች ለመለየት እና ተመጣጣኝ እንግሊዝኛ/ስፓኒሽ/ወዘተ ለመተርጎም በሚሞክሩበት "ቃል በቃል" ለትርጉም አቀራረብ ወይም የሐረጎችንና የፅንሰ-ሀሳቦችን የመጀመሪያ ትርጉም ለማግኘት እና ከዚያም ተመጣጣኝ ትርጉም ለመተርጎም በሚሞክሩበት "ሀሳብ በቃል" አቀራረብ መካከል መወሰን አለባቸው።

ብዙ ዘመናዊ ትርጉሞች በዒላማው ቋንቋ ተፈጥሯዊ የሚመስል ነገር ላይ ለመድረስ እና የመጀመሪያዎቹን ትክክለኝነት ለመጠበቅ የተለያዩ አቀራረቦችን ይጠቀማሉ።
:::

አብዛኛዎቹ ትርጉሞች በይዘቱ እንደሚስማሙ ልብ ማለት አስፈላጊ ነው፣ ነገር ግን የማንኛውም የተወሰነ ትርጉም በጥልቀት ማንበብ አሳሳች ሊሆን ይችላል ምክንያቱም በትርጉሙ ውስጥ ለመወከል አስቸጋሪ የሆኑ በመጀመሪያው ቋንቋ ውስጥ ያሉ ፍችዎችና ግርጌዎች ስላሉ፣ እንዲሁም በጥንቃቄ ካልተጠና የዋናው ደራሲ ትክክለኛ ዓላማ ላይሆኑ የሚችሉ በትርጉም ቋንቋ ውስጥ ያሉ ሀሳቦችን ጠቁመዋል።

መጽሐፍ ቅዱስን ሲያነቡ፣ ምን ለመረዳት እየሞከሩ እንደሆነ እራስዎን መጠየቅ እና ከዚያም ስራዎን ለማሳካት የሚረዱዎትን አንድ ወይም ከዚያ በላይ ትርጉሞችን መምረጥ አስፈላጊ ነው። ለምሳሌ፣ ለመደሰት እና ለመሠረታዊ ግንዛቤ መጽሐፍ ቅዱስን የሚያነቡ ከሆነ፣ እንደ [BSB](https://bereanbibles.com/) ፣ [ESV](https://www.esv.org/) ወይም [NASB](https://www.lockman.org/new-american-standard-bible-nasb/) ያሉ ማንኛውንም ዘመናዊ ትርጉም ይምረጡ። ሆኖም፣ የተወሰነ ሀረግ ወይም ፍች ለመረዳት እየሞከሩ ከሆነ፣ ብዙ ትርጉሞችን እርስ በእርስ ማወዳደር ወይም የአንድ የተወሰነ ክፍል ምንጭ ዕብራይስጥ/ግሪክን በቀላሉ ማየት የሚያስችልዎትን ኢንተርሊኒየር መጽሐፍ ቅዱስን መውሰድ ጥሩ ነው።

ከሁሉም በላይ ግን የመንፈስ ቅዱስን ጥበብ ለማግኘት መጸለይ ነው፣ ምክንያቱም በኢየሱስ ቃላት ውስጥ **“...እርሱ የእውነት መንፈስ ወደ እውነት ሁሉ ይመራችኋል።” - ዮሐንስ 16:13**
