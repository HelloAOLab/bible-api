# መጽሐፍ ቅዱስን ለማጽደቅ የሚያገለግል መጽሐፍ ቅዱሳዊ ሞዴል

**"...በነጻ ተቀበላችሁ፥ በከንቱ ስጡ።" - ማቴዎስ 10:8**

ክርስቲያኖች የኢየሱስ ቃላት የእግዚአብሔር ቃል እንደሆኑና ለሰው ልጅ በነፃ የተሰጡ መሆናቸውን ያምናሉ፤ ኢየሱስ ራሱ የሰውን ሥጋ ለመልበስና ከመከራችን ለመካፈል ማንኛውንም ምቾት ትቶ ነበር።

በተመሳሳይ፣ ሌሎች የእግዚአብሔርን ቃል የሚያከብሩ ልምዶችን እንዳይፈጥሩ የሚያደናቅፉ የክፍያ ግንቦችን ወይም ሌሎች እንቅፋቶችን መፍጠር ከእኛ ይራቅ።

ሙሉ እና ጥራት ያለው የእንግሊዝኛ የመጽሐፍ ቅዱስ ትርጉም ለዓለም በነፃ ለማካፈል ፈቃደኛ የሆነ አጋር ለማግኘት ባደረግነው ፍለጋ፣ ያለምንም የአጠቃቀም ገደብ እና በኤፒአይ አማካኝነት ይህን ለማድረግ ፈቃደኛ የሆኑ ጥቂት አጋሮችን ብቻ ነው ያገኘነው። ልዩ ትኩረት፣ ይህንን API እውን ለማድረግ ላደረጉት [የቤሪያን የመጽሐፍ ቅዱስ ቡድን](https://berean.bible/) ከቃላት በላይ እጅግ አመስጋኞች ነን።

የቤሪያን መጽሐፍ ቅዱስ መፈጠር የተፈጠረው አመራሩ ለሕዝብ አገልግሎት እንደ [ባይብልሃብ](https://biblehub.com/) በማቅረብ እና የፈቃድ ሰጪዎች ወቅታዊ መረጃዎችን በመስጠታቸው፣ የጊዜ ገደቦች ሲያልቁ እና ሌሎች በርካታ ተዛማጅ ጉዳዮችን በማቅረብ የዓመታት ልምድ ስለነበራቸው ነው። በመጨረሻም ባይብልሃብ ቡድን የእንግሊዝኛ ትርጉም ያለ አሳታሚ ወይም የፈቃድ ሰጪ ገደቦች በዓለም ላይ በነፃነት ጥቅም ላይ እንዲውል ለማረጋገጥ የራሳቸውን ትርጉም ለመፍጠር ወሰነ።

ጽሑፎችን ያለክፍያ እና ያለአጠቃቀም ገደብ ለማቅረብ ፈቃደኛ የሆኑ ሌሎች የመጽሐፍ ቅዱስ ትርጉሞች ካሉዎት ወይም የሚያውቁ ከሆነ፣ እባክዎን በ [hello@helloao.org](mailto:hello@helloao.org) ያግኙን።

በመጨረሻም፣ እያንዳንዱ የቅጂ መብት ባለቤት ወይም የመጽሐፍ ቅዱስ ጽሑፎች አሳታሚ አጠቃቀማቸውን የሚገድብ ፈቃድ በቁም ነገር እንዲያገኝ እና ኢየሱስ ሲመለስ ምን ሊላቸው እንደሚችል በጥንቃቄ እንዲያጤን እንጸልያለን።

አመሰግናለሁ!
