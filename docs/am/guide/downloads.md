# ውርዶች

እንደ HTTP API ከመገኘታችን በተጨማሪ፣ ይዘቱን በሚወርዱ ቅርጸቶች እንዲገኝ አድርገናል፦

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 ጊባ) - ኤፒአይ በዚፕ ፋይል ይገኛል። ሙሉውን የመጽሐፍ ቅዱስ ኤፒአይ በአካባቢዎ ኮምፒውተር ላይ ለማግኘት በቀላሉ ያውርዱ እና ይክፈቱት።
-   [bible.db](https://bible.helloao.org/bible.db) (11 ጊባ) - በመጽሐፍ ቅዱስ ኤፒአይ ውስጥ ያለው ሁሉም ይዘት እንደ [SQLite](https://www.sqlite.org/index.html) የውሂብ ጎታ ይገኛል። ይህ ስሪት ለማነፃፀር እና ለመረጃ ትንተና ከ1000 በላይ ትርጉሞችን መፈለግ በጣም ቀላል ያደርገዋል።
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 ጊባ) - ሁሉም የመጽሐፍ ቅዱስ API የእንግሊዝኛ ትርጉሞች እንደ [SQLite](https://www.sqlite.org/index.html) የውሂብ ጎታ ይገኛሉ። ይህ እትም ለማነፃፀር እና ለመረጃ ትንተና ከ1000 በላይ ትርጉሞችን መፈለግ በጣም ቀላል ያደርገዋል።
