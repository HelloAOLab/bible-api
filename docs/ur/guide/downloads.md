# ڈاؤن لوڈز

HTTP API کے طور پر دستیاب ہونے کے علاوہ، ہم نے مواد کو ڈاؤن لوڈ کے قابل فارمیٹس میں دستیاب کرایا ہے:

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - ایک زپ فائل میں دستیاب API۔ اپنے مقامی کمپیوٹر پر مکمل بائبل API دستیاب رکھنے کے لیے بس ڈاؤن لوڈ اور ان زپ کریں۔
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - بائبل API میں موجود تمام مواد [SQLite](https://www.sqlite.org/index.html) ڈیٹا بیس کے طور پر دستیاب ہے۔ یہ ورژن موازنہ اور ڈیٹا کے تجزیہ کے لیے 1000 سے زیادہ تراجم کے ذریعے تلاش کرنا بہت آسان بناتا ہے۔
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - بائبل API کے تمام انگریزی ترجمے [SQLite](https://www.sqlite.org/index.html) ڈیٹا بیس کے طور پر دستیاب ہیں۔ یہ ورژن موازنہ اور ڈیٹا کے تجزیہ کے لیے 1000 سے زیادہ تراجم کے ذریعے تلاش کرنا بہت آسان بناتا ہے۔
