# API

مفت استعمال بائبل API کے لیے حوالہ دستاویزات، زمرہ کے لحاظ سے منظم:

-   [**ترجمہ، کتابیں، اور ابواب**](./translations/README.md) - بائبل کے تراجم، ان کی کتابیں، اور باب کا مواد، [معیاری](./translations/standard.md) اور [آسان](./translations/simplified.md) فارمیٹس میں دستیاب ہے۔
-   [**تفسیریں**](./commentaries/README.md) - بائبل کی تفسیریں، ان کی کتابیں، ابواب اور پروفائلز۔
-   [**ڈیٹا سیٹس**](./datasets/README.md) - ضمنی ڈیٹا سیٹس، جیسے کراس حوالہ جات اور بائبلی اداروں (لوگ، مقامات، واقعات، اور لوگوں کے گروپ)، اور ان کی کتابیں، ابواب اور ادارے۔
-   [**OpenAPI**](./openapi.md) - OpenAPI دستاویز جو API کی وضاحت کرتی ہے، جسے آپ دوسری زبانوں کے لیے کلائنٹس تیار کرنے کے لیے استعمال کر سکتے ہیں۔
