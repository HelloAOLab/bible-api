# Ukulanda

Ngaphezu kokutholakala njenge-HTTP API, senze okuqukethwe kutholakale ngamafomethi angalandwa:

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - I-API itholakala ngefayela le-zip. Mane nje ulande bese uvula i-zip ukuze yonke i-API yeBhayibheli itholakale kukhompyutha yakho yasendaweni.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - Konke okuqukethwe ku-Bible API kuyatholakala njengesizindalwazi [se-SQLite](https://www.sqlite.org/index.html) . Le nguqulo yenza kube lula kakhulu ukusesha izinguqulo ezingaphezu kwe-1000 ukuze kuqhathaniswe futhi kuhlaziywe idatha.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - Zonke izinguqulo zesiNgisi ze-Bible API ziyatholakala njengesizindalwazi [se-SQLite](https://www.sqlite.org/index.html) . Le nguqulo yenza kube lula kakhulu ukusesha izinguqulo ezingaphezu kwe-1000 ukuze kuqhathaniswe futhi kuhlaziywe idatha.
