# Isingeniso

IBhayibheli, izwi likaNkulunkulu eliphefumulelwe, liyiqoqo lemibhalo ebaluleke kakhulu emlandweni womhlaba. Liye lafundwa izizukulwane ezingenakubalwa ngamasiko avela kuwo wonke umhlaba, futhi liqukethe amaqiniso amaningi ayisisekelo lapho ukuphila kwethu konke kwakhelwe khona.

## Mayelana NATHI

[I-AO Lab](https://helloao.org/) yinkampani engenzi nzuzo ezinikele ekuthandeni nasekuphileni iZwi likaNkulunkulu. Umgomo walo msebenzi ukwenza iBhayibheli (nezinsiza ezihlobene nalo) litholakale mahhala kunoma ubani okufanele alidinge ngefomethi elungiselelwe ukusetshenziswa yizinhlelo zokusebenza.

Siyajabula ukubambisana nethimba le [-BSB](https://bereanbibles.com/) . Ngaphandle kosizo lwabo nokusekelwa kwabo, le API ibingeke itholakale.

Uma ungathanda ukufunda kabanzi nge-BSB sicela [uchofoze lapha](https://bereanbibles.com/about-berean-study-bible/) .

## Inothi Mayelana Nokuhumusha

Ekuqaleni labhalwa ngesiHebheru, isiGreki nesi-Aramu sasendulo, iBhayibheli manje selisetshenziswa kakhulu njengeqoqo lezinguqulo ezilimini zesimanje ezidumile njengesiNgisi, isiJalimane, neSpanishi. Ngenxa yokuthi isiHebheru nesiGreki sasendulo sihluke kakhulu ezilimini zethu zanamuhla, kunezinqumo eziningi umhumushi okumelwe azenze ukuze ahumushe iBhayibheli ngokunemba nangokunembile olimini lwesimanje njengesiNgisi. Ngenxa yalokho, ukuhumusha ekugcineni kuyinqubo yokudala yokuhumusha edinga ukucatshangelwa okukhulu kanye nomongo womlando. Ngakho-ke, akukho ukuhumusha okuqondile kweBhayibheli olimini lwesimanje. Lokhu akukunciphisi neze ukuthembeka kwemibhalo ngokujwayelekile, kodwa kusishiya sivulekele engcupheni yokungaqondi kahle inhloso yombhali wokuqala uma sifunda inguqulo eyodwa kuphela.

Namuhla kuye kwenziwa izinguqulo eziningi ezahlukene zeBhayibheli, ngayinye izama izindlela ezahlukene futhi inike isisindo emibonweni ehlukene ukuze izame ukwenza iBhayibheli litholakale kalula futhi liqondakale ngendlela enembile nenembile. Umhumushi ngamunye ufuna ukwenza iBhayibheli liqondakale olimini oluthile, kodwa angase asebenzise izindlela ezahlukene ukuze afinyelele leyo njongo.

::: tip
Isibonelo, abahumushi ngokomlando kufanele banqume phakathi kokuthatha indlela "yezwi nezwi" ekuhumusheni lapho bezama ukuthola izincazelo zokuqala zamagama esiHebheru nesiGreki bese behumusha isiNgisi/isiSpanishi/njll., noma indlela "yokucabanga ngokucabanga" lapho bezama ukuthola incazelo yokuqala yemisho nemibono bese behumusha incazelo efanayo.

Izinguqulo eziningi zanamuhla zisebenzisa izindlela ezihlanganisiwe zokuzama ukufinyelela okuthile okuzwakala kungokwemvelo olimini oluqondiwe ngenkathi futhi kugcinwa ukunemba kwemibhalo yokuqala.
:::

Kubalulekile ukuqaphela ukuthi iningi lezinguqulo liyavumelana ngokuqukethwe, kodwa ukufunda ngokujulile noma yikuphi ukuhumusha okuthile kungadukisa ngoba kunezincazelo kanye nemisho engezansi ekhona olimini lokuqala okungase kube nzima ukuyimelela ekuhumusheni, kanye nemibono ephakanyisiwe ekhona olimini lokuhumusha okungenzeka ingabi yinhloso eqondile yombhali wokuqala uma ingafundwanga ngokucophelela.

Uma ufunda iBhayibheli, kubalulekile ukuzibuza ukuthi uzama ukuqonda ini, bese ukhetha inguqulo eyodwa noma ngaphezulu engakusiza ukufeza umsebenzi wakho. Isibonelo, uma ufunda iBhayibheli ukuze ujabulele futhi uqonde izinto eziyisisekelo, khetha noma yiluphi uhumusho lwesimanje njenge- [BSB](https://bereanbibles.com/) , [ESV](https://www.esv.org/) , noma izinguqulo ze [-NASB](https://www.lockman.org/new-american-standard-bible-nasb/) . Kodwa-ke, uma uzama ukuqonda inkulumo ethile noma incazelo ethile, kungcono ukuqhathanisa izinguqulo eziningi noma ngisho nokufumana iBhayibheli eliphakathi kwemigqa okwenza kube lula ngawe ukubona umthombo wesiHebheru/wesiGreki wendima ethile.

Kodwa okubaluleke kakhulu umthandazo wokucela ukuhlakanipha nokuqondiswa nguMoya oNgcwele, ngoba ngamazwi kaJesu: **“...UMoya weqiniso, uzoniholela kulo lonke iqiniso.” - Johane 16:13**
