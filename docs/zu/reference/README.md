# I-API

Imibhalo yokubhekisela ye-Free Use Bible API, ehlelwe ngokwesigaba:

-   [**Izinguqulo, Izincwadi, kanye Nezahluko**](./translations/README.md) - Izinguqulo zeBhayibheli, izincwadi zazo, kanye nokuqukethwe kwezahluko, kuyatholakala ngamafomethi [ajwayelekile](./translations/standard.md) [nalula](./translations/simplified.md) .
-   [**Amazwana**](./commentaries/README.md) - Amazwana eBhayibheli, izincwadi zawo, izahluko, kanye namaphrofayili.
-   [**Amasethi edatha**](./datasets/README.md) - amasethi edatha engeziwe, njengezinkomba ezivundlile, izinhlangano eziseBhayibhelini (abantu, izindawo, imicimbi, namaqembu abantu), amagama olimi lokuqala oluphakathi kwemigqa, isichazamazwi sikaStrong, kanye namavesi osuku, kanye nezincwadi zawo, izahluko, izinhlangano, nezigaba zamavesi.
-   [**I-OpenAPI**](./openapi.md) - idokhumenti ye-OpenAPI echaza i-API, ongayisebenzisa ukukhiqiza amaklayenti ezinye izilimi.
