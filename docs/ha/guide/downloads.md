# Saukewa

Baya ga kasancewa a matsayin HTTP API, mun samar da abun ciki a cikin tsarin da za a iya saukewa:

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - API ɗin yana samuwa a cikin fayil ɗin zip. Kawai sauke kuma buɗe zip ɗin don samun cikakken API ɗin Littafi Mai Tsarki a kwamfutarka ta gida.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - Duk abubuwan da ke cikin Littafi Mai Tsarki API suna samuwa a matsayin rumbun adana bayanai [na SQLite](https://www.sqlite.org/index.html) . Wannan sigar ta sauƙaƙa bincike ta hanyar fassarori sama da 1000 don kwatantawa da nazarin bayanai.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - Duk fassarar Turanci ta API ɗin Littafi Mai Tsarki suna samuwa a matsayin rumbun adana bayanai [na SQLite](https://www.sqlite.org/index.html) . Wannan sigar ta sauƙaƙa bincike ta hanyar fassarori sama da 1000 don kwatantawa da nazarin bayanai.
