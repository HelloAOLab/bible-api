# API

Documentazione di riferimento per l'API Free Use Bible, organizzata per categoria:

-   [**Traduzioni, libri e capitoli**](./translations/README.md) - Traduzioni della Bibbia, i relativi libri e il contenuto dei capitoli, disponibili in formato [standard](./translations/standard.md) e [semplificato](./translations/simplified.md) .
-   [**Commentari**](./commentaries/README.md) - Commentari biblici, i loro libri, capitoli e profili.
-   [**Set di dati**](./datasets/README.md) - set di dati supplementari, come riferimenti incrociati, entità bibliche (persone, luoghi, eventi e gruppi di persone), parole interlineari in lingua originale, un lessico di Strong e candidati al versetto del giorno, con i relativi libri, capitoli, entità e categorie di versetti.
-   [**OpenAPI**](./openapi.md) - il documento OpenAPI che descrive l'API, utilizzabile per generare client per altri linguaggi.
