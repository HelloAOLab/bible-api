# Download

Oltre a essere disponibili come API HTTP, abbiamo reso i contenuti disponibili anche in formati scaricabili:

-   [api.zip](https://bible.helloao.org/api.zip) (1,5 GB) - L'API è disponibile in un file zip. Basta scaricarlo ed estrarlo per avere l'intera API della Bibbia disponibile sul computer locale.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - Tutti i contenuti dell'API della Bibbia sono disponibili come database [SQLite](https://www.sqlite.org/index.html) . Questa versione semplifica notevolmente la ricerca tra oltre 1000 traduzioni per il confronto e l'analisi dei dati.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1,5 GB) - Tutte le traduzioni inglesi dell'API della Bibbia sono disponibili come database [SQLite](https://www.sqlite.org/index.html) . Questa versione semplifica notevolmente la ricerca tra oltre 1000 traduzioni per il confronto e l'analisi dei dati.
