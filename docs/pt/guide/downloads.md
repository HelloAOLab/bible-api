# Downloads

Além de estar disponível como uma API HTTP, disponibilizamos conteúdo em formatos para download:

-   [api.zip](https://bible.helloao.org/api.zip) (1,5 GB) - A API está disponível em um arquivo zip. Basta baixar e descompactar para ter toda a API da Bíblia disponível em seu computador.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - Todo o conteúdo da API da Bíblia disponível como um banco de dados [SQLite](https://www.sqlite.org/index.html) . Esta versão facilita muito a busca em mais de 1000 traduções para comparação e análise de dados.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1,5 GB) - Todas as traduções em inglês da Bíblia disponíveis como um banco de dados [SQLite](https://www.sqlite.org/index.html) . Esta versão facilita muito a busca em mais de 1000 traduções para comparação e análise de dados.
