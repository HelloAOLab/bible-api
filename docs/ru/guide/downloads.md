# Загрузки

Помимо доступности через HTTP API, мы также предоставили контент в форматах для скачивания:

-   [api.zip](https://bible.helloao.org/api.zip) (1,5 ГБ) — API доступен в zip-архиве. Просто скачайте и распакуйте, чтобы получить полный API Библии на свой локальный компьютер.
-   [bible.db](https://bible.helloao.org/bible.db) (11 ГБ) — Весь контент Bible API доступен в виде базы данных [SQLite](https://www.sqlite.org/index.html) . Эта версия значительно упрощает поиск по более чем 1000 переводам для сравнения и анализа данных.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1,5 ГБ) — Все английские переводы Библии API доступны в виде базы данных [SQLite](https://www.sqlite.org/index.html) . Эта версия значительно упрощает поиск среди более чем 1000 переводов для сравнения и анализа данных.
