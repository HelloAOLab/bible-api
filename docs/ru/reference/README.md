# API

Справочная документация по API Free Use Bible, организованная по категориям:

-   [**Переводы, книги и главы**](./translations/README.md) — переводы Библии, их книги и содержание глав, доступные в [стандартном](./translations/standard.md) и [упрощенном](./translations/simplified.md) форматах.
-   [**Комментарии**](./commentaries/README.md) — комментарии к Библии, их книги, главы и библейские очерки.
-   [**Наборы данных**](./datasets/README.md) — дополнительные наборы данных, такие как перекрестные ссылки и библейские объекты (люди, места, события и группы людей), а также их книги, главы и объекты.
-   [**OpenAPI**](./openapi.md) — документ OpenAPI, описывающий API, который можно использовать для создания клиентов для других языков.
