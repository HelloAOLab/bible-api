# Aflaaie

Benewens die beskikbaarheid as 'n HTTP API, het ons inhoud beskikbaar gestel in aflaaibare formate:

-   [api.zip](https://bible.helloao.org/api.zip) (1.5 GB) - Die API is beskikbaar in 'n zip-lêer. Laai dit eenvoudig af en pak dit uit om die hele Bybel-API op jou plaaslike rekenaar beskikbaar te hê.
-   [bible.db](https://bible.helloao.org/bible.db) (11 GB) - Al die inhoud in die Bybel API is beskikbaar as 'n [SQLite-](https://www.sqlite.org/index.html) databasis. Hierdie weergawe maak dit baie makliker om deur meer as 1000 vertalings te soek vir vergelyking en data-analise.
-   [bible.eng.db](https://bible.helloao.org/bible.eng.db) (1.5 GB) - Al die Engelse vertalings van die Bybel API is beskikbaar as 'n [SQLite-](https://www.sqlite.org/index.html) databasis. Hierdie weergawe maak dit baie makliker om deur meer as 1000 vertalings te soek vir vergelyking en data-analise.
