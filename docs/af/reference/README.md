# API

Verwysingsdokumentasie vir die Free Use Bible API, georganiseer volgens kategorie:

-   [**Vertalings, Boeke en Hoofstukke**](./translations/README.md) - Bybelvertalings, hul boeke en hoofstukinhoud, beskikbaar in [standaard-](./translations/standard.md) en [vereenvoudigde](./translations/simplified.md) formate.
-   [**Kommentare**](./commentaries/README.md) - Bybelkommentare, hul boeke, hoofstukke en profiele.
-   [**Datastelle**](./datasets/README.md) - aanvullende datastelle, soos kruisverwysings, Bybelse entiteite (mense, plekke, gebeure en mensegroepe), interlineêre woorde in die oorspronklike taal, 'n Strong se leksikon, en vers-van-die-dag-kandidate, en hul boeke, hoofstukke, entiteite en verskategorieë.
-   [**OpenAPI**](./openapi.md) - die OpenAPI-dokument wat die API beskryf, wat jy kan gebruik om kliënte vir ander tale te genereer.
